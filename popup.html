lightbulb Claude Tips

The Math
Your 10th message costs 11x more than your 1st. Claude rereads every message in history for every turn.
Force Claude to drop fluff and "talk like caveman." Reduces output tokens by up to 65%.
Token Hacks
Edit your original prompt instead of sending corrections. Replaces history instead of multiplying it.
3 questions in 1 prompt = 1 context load. 3 separate prompts = 3 context loads. Batch to stay under limits.
Fresh chat every 15-20 messages. Ask for a summary, carry it to a new chat, and ditch the bloat.
System Limits
Avoid 5 AM–11 AM PT. Same query consumes more session limit during peak hours.
Haiku for drafts/grammar. Sonnet for real work. Opus for deep thinking. Don't waste budget on Sonnet for basic tasks.
Prompting
Structure inputs: Role (0.1% Expert) -> Task -> Context -> Constraints -> Ask for clarifying questions.
Ask AI to "beat up" your ideas. Identify blind spots, weak data, and unproven assumptions.
Knowledge & Tools
Maintain a local .md file as a single source of truth for coding standards and brand voice.
Stack MCP with Skills. Give AI access to real data (Gmail, Drive, Slack) to execute work, not just consult.
Use the mobile app to approve permissions for long-running Claude Code tasks while away from your desk.
