Core insight

Claude counts tokens, not messages. Every new reply rereads the entire conversation history, so longer chats burn far more.

Your 10th message can cost 11x more than your first because Claude rereads the full conversation each turn.
Every word Claude generates is billed too. Shorter answers save both input and output tokens.
Asking Claude to "talk like a caveman" can cut output token use by up to 65%.
Chat discipline
Fix your original prompt, then regenerate. That replaces the exchange instead of inflating the chat history.
When a conversation grows long, summarize it and start a new chat. Keep context, lose the bloat.
One prompt with three tasks is one context load. Three separate prompts is three context loads.
Measure & reuse
Inspect Claude Code logs locally so you can see real token usage and cost drivers.
Put repeated documents in Projects once. Cached content avoids repeated retokenization.
Save your role, style, and formatting once in memory instead of retyping it every new chat.
Model control
Turn off Web Search, connectors, and Advanced Thinking unless you need them.
Use Haiku for grammar checks, quick edits, and short drafts. Save Sonnet/Opus for heavier work.
Session strategy
Use multiple sessions each day. Your rolling 5‑hour window resets usage over time.
Peak window is roughly 5 AM–11 AM PT on weekdays. Off-peak stretches your plan.
Turn on extra usage with a strict monthly cap so work doesn’t stop when your session limit hits.
